# SmartCart AI — Project Handover Document

This document summarizes the progress, architecture, and current state of the **SmartCart AI** project. You can use this to quickly understand the codebase and continue development.

## 1. Tech Stack & Architecture
- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (with custom Material Design 3 inspired tokens in `globals.css`)
- **Animations**: Framer Motion (page transitions, micro-interactions, layout animations)
- **Icons**: Lucide React
- **State Management**: React Context API + `useReducer` (`AppContext.tsx`)
